# QuickWorkout AI

Експрес-тренер для студентів: коротке домашнє тренування на 7, 12 або 15 хвилин
без інвентарю. Працює офлайн із вбудованого банку вправ, а з ключем OpenRouter —
генерує комплекси через AI.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

У PowerShell, якщо `npm.ps1` заблокований політикою:

```powershell
& "C:\Program Files\nodejs\npm.cmd" run dev
```

Інші команди: `npm run build`, `npm run preview`, `npm run typecheck`, `npm run lint`.

## API-ключ

Ключ OpenRouter вводиться через кнопку «API Key» і зберігається **лише локально**
в `localStorage` цього браузера. Він не надсилається на сервер застосунку
(запити йдуть напряму в OpenRouter). Без ключа або при помилці AI застосунок
показує резервний комплекс і повідомляє причину.

## Supabase (необов'язково)

Синхронізація історії тренувань між пристроями вмикається лише за наявності
змінних середовища. Скопіюйте `.env.example` у `.env`:

```
VITE_SUPABASE_URL=https://<project>.supabase.co
VITE_SUPABASE_ANON_KEY=<anon key>
```

Потім:

1. Виконайте `supabase/schema.sql` у SQL Editor.
2. Увімкніть `Authentication → Sign In / Providers → Anonymous sign-ins`.
3. Перезапустіть dev-сервер.

Застосунок створює анонімну сесію, а RLS-політики обмежують доступ кожного
користувача його власними записами. Якщо Supabase не налаштований, жодних
мережевих запитів до нього не робиться, а історія зберігається локально.

## Що зберігається локально

- `quickworkout_supabase_key` — ключ OpenRouter (лише цей браузер).
- `quickworkout_history` — останні 100 завершених тренувань.

Історія пишеться один раз після завершення тренування — і по таймеру, і після
«Пропустити».

## Відомі обмеження

- Якщо вкладка довго у фоні, браузер може призупинити таймери; відлік
  перераховується за реальним часом під час наступного тіку.
- PWA оновлюється автоматично; під час активного тренування оновлення може
  перезавантажити сторінку.
